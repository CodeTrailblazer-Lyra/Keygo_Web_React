# 2026-08-26 工作日志

## 修复：关闭弹窗后整页崩溃 → 卡在加载动画（严重 Bug）
- **现象**：点击「立即获取」打开 Modal，关闭后页面自动重回加载态（index.html 的 `#root:empty` 转圈动画），界面始终空白、无法渲染、交互全失。
- **根因**：`src/utils/modalScrollLock.ts` 的 `releaseModalOverlay()` 在 antd `afterClose` 回调里对 **React 仍在管理的弹窗 Portal 节点**（`.ant-modal-root`）执行了 `root.remove()`。antd 在 `afterClose` 之后才会由 React 卸载该 Portal；此时节点已被我们移除，React 提交阶段 `removeChild` 命中已脱离的节点 → 抛出 `NotFoundError` → React 19 卸载整棵树 → `#root` 变空 → 触发 `#root:empty` 的永久转圈。
- **修复**：`releaseModalOverlay()` 改为**非破坏性**——只清除滚动锁定（移除 `@rc-component/portal` 注入的 `rc-util-locker-*` `<style>`、清除 `ant-scrolling-effect` 类与 body/html 的 overflow/width），对「已完全关闭却残留」的 `.ant-modal-root` 仅设 `display:none !important; pointer-events:none !important` 中和，**绝不 removeChild**。`useModalOverlayCleanup` + `afterClose={releaseModalOverlay}` 的接入保持不变。
- **验证**：`tsc -b` 零错误；`npm run build`（含 chunk 循环检查 + 预压缩）通过；无头 Chrome 加载构建产物，`#root` 正常渲染（非空）、控制台无 `removeChild`/`TypeError`/`NotFoundError`。Modal 关闭的 E2E 需后端登录态，建议本地 `npm run dev` 实测点「立即获取」→ 关闭，确认页面正常。

## 动画优化：消除冗余双重入场 + 统一动效
- `src/components/FadeIn.tsx` 新增 `animateOnMount` prop（默认 true）+ 基于 `useAnimationControls` 的刷新重播（refreshKey 变化时仍渐入，不受 animateOnMount 影响）。
- 页面级内容容器（`/fetch` 统计网格、`/mycodes`、`/list`→LogsView、`/admin` 四张卡片）的 `FadeIn` 设为 `animateOnMount={false}`，**让整页滑动（AnimatedOutlet 的左右滑动）成为唯一入场**，消除「整页滑动 + 内容再渐入」的重叠双重动画；数据刷新淡入保留。
- `/login` 的 `FadeIn` 保持 `animateOnMount` 默认（登录页无整页滑动，需自身入场）。
- 既有动效（页面方向感滑动、统计数字补间 AnimatedNumber、公告 AnimatedList 错峰、hover/按压反馈、弹窗 antd 内置、reduced-motion 降级）保留，整体节奏/缓动仍由 `src/anim/motion.ts` 令牌统一。

## 查询页筛选重构：双搜索框合并为单一统一搜索（修 Bug）
- **问题/设计**：原查询页有两个搜索框——「搜索激活码/备注」（后端 `listCodes` 关键字，防抖 400ms）与「按获取人筛选」（纯前端对**当前已加载页**过滤）。后者是 Bug：只在当页数据里匹配获取人，既与后端关键字框行为不一致，又无法搜到未加载页的获取人。
- **方案**：合并为**单一统一搜索框**，同时模糊匹配 激活码/备注/获取人 三字段；改为**前端拉取全量数据（穿透分页，每页 100、上限 50 页）后在本地做组合筛选 + 本地分页**。状态分段（全部/未使用/已使用）与搜索关键词组合生效，输入即时（useMemo）实时更新。
- **新增**：`hasActiveFilter` 时显示「清除筛选」按钮（一并重置状态 + 关键词）；空状态区分「暂无激活码数据」与「未找到匹配的结果」（带清除筛选入口）；筛选后当前页越界自动回落。
- **改动文件**：`src/views/ListView.tsx`（移除 `keyword`/`fetchUserFilter`/`codes`/`loadCodes`/防抖定时器，新增 `allCodes`/`loadAllCodes`/`filtered`/`paged`/`searchText`/`clearFilters`/`emptyNode`）、`src/views/ListView.css`（`.toolbar-clear`、`.list-empty*` 及暗色）。
- **验证**：`tsc -b` 零错误；`vite build` 通过（构建到临时 `dist-verify` 已移出仓库）；无头 Chrome 加载首屏无崩溃（未登录态显示登录页，印证 SPA 正常挂载）。查询页交互需 `npm run dev` + 后端登录态实测。
