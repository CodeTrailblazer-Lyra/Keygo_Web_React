## 复制体验强化 + 单位创建时间归一化 + 记住上次单位（凌晨追加）

1. **copyText 降级链路重写**（utils/index.ts）：原实现 `navigator.clipboard.writeText` 抛错时直接失败不走兜底。现改为：安全上下文 + clipboard API 可用则优先；失败/受限（iOS Safari、非 HTTPS）降级为隐藏 textarea + execCommand('copy')，且用 contentEditable+readOnly+setSelectionRange 兼容 iOS（select() 在 iOS 无效），保存/还原用户原有选区。
2. **禁用激活码选中效果**：`.code-chip`/`.batch-result-item` 的 `user-select: all` → `none`（含 -webkit-touch-callout:none 禁 iOS 长按菜单），两处点击元素加 `onMouseDown={e.preventDefault()}` 阻止进入文本选择模式；hover/active 视觉暗示保留。
3. **管理页单位创建时间不显示修复**（api/units.ts）：前端绑定 `createTime` 而后端契约为 `created_at`（snake_case），且可能为时间戳。新增 `normalizeUnit`/`normalizeTime`：兼容 created_at/createdAt/createTime 三种命名、字符串/秒级/毫秒级时间戳，统一归一化为 ISO 字符串；listUnits/addUnit 均走归一化。根因仍是后端未按契约返回该字段（接口本身 404 未实现），前端已做成字段无关的防御性解析。
4. **记住上次所选使用单位**（FetchView）：localStorage key `keygo-last-claim-unit`；`openClaimModal` 回填上次单位（单位已删除则回退为空，初次使用无记录默认空）；`doClaim` 成功后 `saveLastUnit`（清空选择则删记录）。
5. 验证：rm -rf dist + tsc -b + vite build 通过（exit 0），preview 4180 端口存活。
