## 查询页 / 弹窗：使用单位默认留空 + 移动端交互优化
- **使用单位下拉默认「不选择」**：`src/views/FetchView.tsx` 申领弹窗 Select 新增 `value:''` 的「不选择（留空）」选项并设为默认，移除 `allowClear`/`placeholder`；`unit` 默认 '' → 显示该项。提交时空值走 `claimCode(undefined)`（备注保持原样），`saveLastUnit('')` 清除记录、下次默认留空（用户可改回初始值）。
- **移动端下拉滚动穿透修复（加固）**：根因——本应用真实滚动容器是 `<html>`，而 antd 滚动锁定类 `ant-scrolling-effect` 可能直接挂在 `<html>` 或 `<body>`，既有 `:has()` CSS 覆盖不到「类挂在 html 自身」的情形，导致弹窗内（含使用单位下拉）滑动时底层根页面同步滚动。
  - `src/utils/modalScrollLock.ts` 的 `initModalScrollLock()` 改为用 `MutationObserver` 监听 `ant-scrolling-effect`（html/body/任意后代）增删，同步锁死/释放 `documentElement.style.overflow`。
  - `src/styles/main.css` 锁定规则扩展为 `html.ant-scrolling-effect, body.ant-scrolling-effect, html:has(.ant-scrolling-effect){overflow:hidden!important}`。
- **查询页移动端长按操作菜单**：`src/views/ListView.tsx` 新增 `useIsMobile()`（≤768px）。移动端操作列改为窄「⋮」按钮（width 48），并对整行 `onRow` 加 500ms 长按检测 → 弹出操作选择菜单（Modal `.row-action-sheet`，含 使用/恢复/删除/取消）；桌面端保留原内联按钮。`runRowAction` 先关菜单、延时 320ms 再唤起确认弹窗，避免两个弹窗滚动锁相互覆盖。新增 `AppIcon` 图标 `more`（EllipsisOutlined）。
- **验证**：`tsc -b` 零错误；`vite build`（临时 `dist-verify2`）通过；无头 Chrome 首屏挂载无 `TypeError/ReferenceError/NotFoundError`。
