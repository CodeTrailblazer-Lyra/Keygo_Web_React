## 修复：移动端登录页卡片底部空白
- 根因：`src/views/LoginView.css` 移动端媒体查询中 `.login-card { flex:1 }` 把 Arco Card 拉伸到整屏高度，而 `.arco-card-body` 未撑开，导致卡片（arco-card-bordered）内底部大片空白；桌面端无 flex:1 故正常。
- 修复：移动端去掉卡片 `flex:1`，改为内容自适应高度；`.login-wrapper` 增加 `justify-content:center` + `overflow-y:auto` + `min-height:100dvh`，使品牌区+卡片整体垂直居中且极小屏可滚动。
- 注：`npm run build` 仍会触发沙箱 safe-delete 拦截 Vite 清空 dist（与改动无关），需先 `rm -rf dist` 再构建。
